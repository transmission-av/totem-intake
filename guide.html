Totem Content Guide

Name your files the way this page shows, and your signage runs itself — right sign, right screen, right minute, all event long, with nobody babysitting a screen.

How it works

1You send three things A floor-plan with numbered totem positions, your content files, and your attendee agenda.
2We pre-program everything Every sign is scheduled to its screen and time window before we even arrive on site.
3The show runs itself Screens wake up, rotate, switch and go dark on schedule. Our last event ran four days untouched.

The filename does the work

Each file tells us where it plays, when it plays, and what it is — in one name:

T02_Mon_0850-0950_NoelleRussell-Keynote.jpg
WHERE
Totem number from the map. Several: T01+02+12. Every totem: ALL
WHICH DAY
Sat Sun Mon Tue Wed… — or daily for every event day
WHEN
24-hour start–end, or allday. 24-hour means we never guess AM/PM
WHAT
Short name — letters, numbers and hyphens only
ExampleWhat it tells us
T02_Mon_0850-0950_NoelleRussell-Keynote.jpg Totem 2, Monday, 8:50–9:50 AM — keynote sign holds the screen
T01+02+12_Wed_0900-0945_MakingItEasier.jpg All three ballroom-entrance totems, Wednesday morning session
T08+09_Mon_1700-2045_ChildrensParty.mp4 Video on totems 8 & 9, Monday 5:00–8:45 PM
ALL_Sun_allday_SundayAgenda.jpg Sunday's agenda rotates on every screen, all day Sunday

✓ Helps us help you
  • 24-hour times: 1815-2030, never 6.15-8.30
  • Room name + time printed on the artwork for session signs
  • One file per sign, final exports only
  • Replacing a file? Same filename — and tell us
✗ Slows your show down
  • breakfast.jpg, CEO-final-FINAL2.jpg — we have to ask what/where/when
  • Vague timing like "after4"
  • Spaces, apostrophes, & # ( ) in names
  • Working files, duplicate export folders, print files mixed in
Why artwork matters twice: we cross-check every filename against your agenda and the room/time printed on the sign itself. On our last show that catch fixed two mislabeled files before a single attendee saw them.

File specs

🖼 Images

Size
Native screen size (we'll tell you, e.g. 320×1080) or an exact multiple
Format
JPEG (high quality) or PNG
Color
sRGB
Max
20 MB per file

🎬 Video

Format
MP4 · H.264
Frame rate
30 fps or lower
Export from
Desktop software (After Effects, Premiere, Media Encoder), not a web or phone app. Designing in Adobe Express is fine; export the final video on desktop. Ask us for our Media Encoder preset.
Size
Same as images — native or exact multiple
Audio
None (totems are silent)
Loops
First and last frame should match
Max
3 min · 500 MB per file

Before you hit send

  • ☐ Placement map with numbered positions (T01, T02, …) included
  • ☐ Attendee agenda included
  • ☐ Every file named to the pattern above
  • ☐ Session signs show room + time on the artwork
  • ☐ One shared folder (Dropbox works great), 5+ days before load-in
